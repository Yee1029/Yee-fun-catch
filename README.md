# 夾夾管家｜娃娃機營運管理系統（第一版）

這是可直接部署到 GitHub Pages 的靜態網站原型，使用原生 HTML、CSS、JavaScript，不需要 npm 或建置工具。

## 目前可操作
- 營運總覽：後台版型與示意營收資料。
- 場地管理：新增、編輯、搜尋、停用／啟用場地。
- 機台管理：新增、編輯、搜尋、篩選、停用／啟用機台。
- 機台設定所屬場地、台號、每月租金、每格投幣金額。
- 台號只需在同一場地內唯一；不同場地可使用相同台號。
- 場地租金合計依所屬機台計算；可匯出機台清單 CSV。
- 手機與桌面響應式介面。

## 上傳 GitHub Pages
1. 解壓縮此 ZIP。
2. 在 GitHub 建立新的 repository，例如 `claw-machine-manager`。
3. 將 `index.html`、`styles.css`、`app.js`、`README.md` 放在 repository 根目錄。
4. 到 **Settings → Pages**。
5. 在 Build and deployment 選擇 **Deploy from a branch**。
6. Branch 選 `main`，資料夾選 `/(root)`，按 Save。
7. 等待部署完成，從 Pages 頁面顯示的網址開啟網站。

## 重要限制
- 此版是前端原型，還不是正式多使用者系統。
- 場地／機台資料儲存在目前瀏覽器的 `localStorage`，不同裝置不會同步；清除瀏覽器資料可能造成資料遺失。
- 首頁營收、成本、營利、排行及活動是示意數據，不能當作實際帳務。
- 投幣紀錄、特殊活動結算、歷史資料庫、登入權限與正式報表尚未接上。
- 正式營運前需接入資料庫及後端 API，並保存不可覆寫的讀數歷史、租金生效期間與每期快照。

### 接手機台起始讀數
新增或編輯機台時，請填寫「接手時目前投幣讀數」。例如交接讀數為 181540，第一次抄表若為 181800，系統只計算 181800 - 181540 = 260 格的營收，不會把接手前累積的讀數當成本次營收。後續抄表則以前一次實際抄表讀數作為基準。


### V5 營運總覽統計修正
修正本期週期計算中 Date 物件被當成日期字串處理的問題。營運總覽與營利分析會依每月 10 日至次月 10 日（次月 10 日不含）的週期統計抄表營收與商品成本，並扣除營運中機台的月租金。公式：本期營利＝本期投幣營收－本期商品成本－營運中機台租金合計。
